===============================================================
 PART 1 - THE SHARED FOLDER (do this once)
===============================================================

We are using ONEDRIVE, not iCloud. Reason: OneDrive is already
installed, signed in and running on your laptop. iCloud would
mean installing and configuring something new for no gain.

I HAVE ALREADY MADE THE FOLDERS ON THE LAPTOP. They are at:

    C:\Users\604dr\OneDrive\Deez Plants\
        walks\      <- walks go here, transcripts come back here
        ai\         <- the AI round-trip lives here

You only need to make your PHONE able to see them.


STEP 1.1 - Install OneDrive on your iPhone
-------------------------------------------
Open the App Store, search "OneDrive", install the blue cloud
one made by Microsoft. It is free.


STEP 1.2 - Sign in
-------------------------------------------
Open it and sign in with the SAME Microsoft account your laptop
uses. If you are not sure which that is, on the laptop click the
blue cloud in the bottom-right taskbar - it shows the email.


STEP 1.3 - Check you can see the folder
-------------------------------------------
On the phone, open the OneDrive app. You should see a folder
called "Deez Plants" with "walks" and "ai" inside it.

If you do: setup is done, forever.

If you do NOT see it: the phone is on a different Microsoft
account than the laptop. Fix that before going further.


STEP 1.4 - Make it appear in the Files app
-------------------------------------------
This is what lets you SAVE into it from the app.

  Open the Files app on your phone
  Tap Browse (bottom right)
  Tap the three dots at the top right
  Tap Edit
  Turn ON the switch next to OneDrive
  Tap Done

Now "OneDrive" shows in Files alongside iCloud Drive.


===============================================================
 PART 2 - START THE WATCHER (once per reboot)
===============================================================

The watcher is a small program that sits waiting. When a walk
arrives in the folder it unzips it, transcribes it, and puts the
transcript back - with no commands from you.


STEP 2.1 - Start it
-------------------------------------------
On the laptop, open the deez-plants folder and DOUBLE-CLICK:

    start-watching.bat

A black window opens and says:

    Deez Plants - watching for walks
    --------------------------------
    Watching C:\Users\604dr\OneDrive\Deez Plants\walks
    Waiting...

That is it working. LEAVE THAT WINDOW OPEN.


STEP 2.2 - Does it have to be running all the time?
-------------------------------------------
No. It only needs to be running at the moment a walk arrives.

If you drop a walk in while it is NOT running, nothing is lost -
the zip just sits there. Start the watcher later and it picks it
up within ten seconds.

So: start it when you get back from a walk, or leave it running
all day if you prefer. Either works.


STEP 2.3 - Stopping it
-------------------------------------------
Close the window with the X. That is all - Ctrl+C works too but
you do not need to remember it.

It does NOT keep running in the background after the window is
closed, and it does not start itself when the laptop boots. If
you would rather it did start automatically, say so and I will
set that up - it is a five-minute job and then you would never
think about it again.


STEP 2.4 - A shortcut so you do not go hunting
-------------------------------------------
I have put a shortcut on your Desktop called

    Deez Plants - watch for walks

Double-click that instead of going into the project folder.


===============================================================
 PART 3 - TRANSCRIBE A WALK (every time, four taps)
===============================================================

STEP 3.1 - On the phone, export the walk
-------------------------------------------
  Open the app
  Tap More, then Recordings
  Find the walk
  Tap "Export for Whisper"
  The Share sheet opens
  Tap "Save to Files"
  Choose OneDrive > Deez Plants > walks
  Tap Save

That is your part done.


STEP 3.2 - Wait
-------------------------------------------
Watch the black window on the laptop. Within a minute or two it
says:

    Found deez-plants-SES-....zip
      unzipped into deez-plants-SES-...\
      transcribing...

THE FIRST TIME EVER, it will sit silent for up to five minutes
downloading the model - about 500 MB. It is not stuck. Leave it.
Every run after that is quick: two minutes of walk takes well
under a minute.

When it finishes:

      wrote 2026-09-14 1833 walk 4 - TRANSCRIPT.txt
      done. Open the transcript on your phone and paste it in.

The file you want is always the one with TRANSCRIPT in capitals,
sitting loose in the walks folder - not the copy inside the
walk's own subfolder. They are identical; the loose one is there
so you never have to go digging.


STEP 3.3 - Put it into the app (no copying needed)
-------------------------------------------
  Open the app
  More > Recordings
  Find THE SAME walk
  Tap "Add transcript"
  Tap the green "Choose the transcript file" button
  The iPhone file picker opens ON RECENTS - that is normal
  Tap "Browse" at the BOTTOM RIGHT
  Tap OneDrive > Deez Plants > walks
  Tap the file ending "- TRANSCRIPT.txt"

DO THIS ONCE AND IT GETS EASIER. iOS remembers where you were
last, so from the second walk on the picker opens straight into
the walks folder.

WORTH 10 SECONDS NOW - make it a favourite:
  Open the Files app
  Browse > OneDrive > Deez Plants
  Press and hold the "walks" folder
  Tap Favourite

It then sits at the top of Browse forever, one tap away, in the
picker as well as in Files.
  Tap Save

That is it. You do NOT need to open the file, select all, or
copy anything. Pick the file and the app reads it.

The picker reopens wherever you were last, so from the second
walk onwards it lands in the right folder already.

(The paste box underneath still works if you ever want to type
or dictate something yourself. That gets marked "unverified",
because there are no timestamps to check it against.)


WHY THIS LAST STEP IS YOURS: the transcript attaches to the
walk, and the walk only exists on the phone that recorded it.
iOS will not let a web page reach into a folder on its own, so
you have to hand it the file. Two taps, and that is the whole of
your involvement.

===============================================================

This is the half of the app that has never been tested. It is
how the AI sees your record and proposes changes you approve.

-------------------------------------------
  In the app: More > Back up > Save my record
  Save it anywhere - Files, OneDrive, wherever.

You have never applied an update before. If anything goes odd,
this is the undo.


STEP 4.1 - Make the package
-------------------------------------------

  Save to Files > OneDrive > Deez Plants > ai


STEP 4.2 - Hand it to your GPT plant bot
-------------------------------------------
SET THE PROJECT UP ONCE. Give it, as its instructions or
knowledge files:

    GPT-PROJECT-BRIEF.txt   (from PART 1 down)
    FIELD_DEFINITIONS.md
    gpt-prompt.txt

All three are in C:\Users\604dr\deez-plants

The brief tells it where this project got to, what the app
became, the rules it cannot break, and what you want settled
with it. Its FIRST reply should be its honest read of where you
are - not an update file. There are five open questions in it
for you to work through together.

DO NOT upload the source code. It is a React app; thousands of
lines about screens and almost nothing about plants. If it wants
to look at something specific, give it the GitHub link:
github.com/deez-plants/deez-plants.github.io

THEN, EACH TIME: upload the review package zip from
OneDrive > Deez Plants > ai, and ask for an update file.

Attach photos to the chat by hand if you want an opinion on how

(You can also just ask ME on the laptop - I can read the folder
directly, no uploading. But you wanted the plant bot to do the
thinking, so this is the path.)


STEP 4.3 - Bring it back
-------------------------------------------
  In the app: More > Apply AI update
  Tap "Choose file"
  Pick the update file from OneDrive > Deez Plants > ai

Same as the transcript - pick the file, no copying. There is a
paste box as well if you prefer it.

STEP 4.4 - Approve row by row
-------------------------------------------
Every proposed change is shown on its own with its reason. You
accept or reject EACH ONE. There is no apply-all button and
there never will be - that is deliberate.

Your own notes are never touched by any of this.


===============================================================
 PART 5 - IF SOMETHING GOES WRONG
===============================================================

THE BLACK WINDOW SAYS "python is not recognized"
  Close it, reopen it, try again. If it persists, tell me.

THE WALK NEVER APPEARS ON THE LAPTOP
  OneDrive has not synced yet. Check the blue cloud icon in the
  taskbar - if it is spinning, wait. If it has a red X, OneDrive
  needs attention.

THE TRANSCRIPT NEVER APPEARS ON THE PHONE
  Same thing in reverse. Give OneDrive a minute.

THE TRANSCRIPT STOPS EARLY
  Look in the walk's folder for what-happened.txt and send me
  what it says. Do not try to work it out from the numbers - the
  walk keeps its own account now, and that is what I need.

IT SAYS COVERAGE: FAIL
  Read the report at the top of the transcript. Going quiet is
  no longer a failure, so if it fails now there is a real
  reason. Send me those lines.

ANYTHING ELSE
  Copy whatever the black window printed in RED and send it.
  Red is the error; the rest is noise.


===============================================================
 PART 6 - WHAT EACH FOLDER IS FOR
===============================================================

OneDrive\Deez Plants\walks\
    You drop exported walks here.
    Transcripts appear here.
    Each walk also gets its own subfolder with the audio in it -
    open those to LISTEN to a walk. If a walk was interrupted it
    holds several files, -part1, -part2 and so on. They all
    play. That is deliberate: gluing them makes a file that
    stops at the first join.
    Finished zips are moved into "transcribed" so they are never
    done twice.

OneDrive\Deez Plants\ai\
    Review packages out, update files back.

deez-plants\My_content_to_share\
    The old manual folder. Nothing new needs to go here - it is
    where tonight's walk was split by hand. Keep or delete.

ONE WARNING, and the watcher protects you from it:
Every export contains a file called markers.json. If you ever
unzip two walks into the SAME folder by hand, the second
overwrites the first - and the transcript then credits one
walk's words to the other walk's plants, with nothing anywhere
looking wrong. The watcher gives every walk its own folder. Let
it do the unzipping.
